# 大肥鱼 2.0

大肥鱼 2.0 的 Agent 内核。项目目标是让机器人具备持续状态、长期记忆、目标、主动行动和可验证的工具调用能力。

当前版本先提供安全的基础层：

- SQLite 记忆和任务存储
- `observe` 观察模式
- 主人专用的状态、暂停、恢复、记忆和目标命令
- 群消息观察和按群保存近期记忆

## AstrBot 命令

```text
agent状态
agent暂停
agent恢复
agent记住 内容
agent记忆
agent目标 目标内容
agent任务
agent完成 任务编号
```

主动发言、浏览器控制、电脑控制和插件自我生成会在后续阶段加入。高风险动作会经过权限策略和人工确认。

## 开发约定

日常开发在 `dev` 分支进行。提交前至少运行 Python 语法检查，并保留可回滚的提交记录。
